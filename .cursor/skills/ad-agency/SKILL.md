# Ad Agency

광고 대행사 캠페인 제작을 **단계별로 조율**하는 오케스트레이터입니다. 각 단계는 지정된 서브에이전트(`.cursor/agents/`)를 호출하고, 결과물을 번호가 붙은 마크다운 파일로 저장합니다.

## 산출물 경로

캠페인별 폴더에 저장합니다. 브랜드명은 파일명에 쓰기 좋게 영문·숫자·하이픈으로 정규화합니다.

```
campaigns/{brand-slug}/
├── 01_ae_brief.md
├── 02_copy.md
├── 03_image.md
├── 04_video.md
├── 05_outdoor.md
├── 06_creative.md
├── 07_review.md
└── 08_campaign_bible.md
```

폴더가 없으면 생성합니다.

## 팀·에이전트 매핑

| 단계 | 역할 | 에이전트 | 출력 파일 | 실행 방식 |
|------|------|----------|-----------|-----------|
| 2 | AE | `ad-ae` | `01_ae_brief.md` | 순차 |
| 3 | 카피라이터 | `ad-copywriter` | `02_copy.md` | 순차 |
| 4 | 이미지팀 | `ad-image-team` | `03_image.md` | **병렬** |
| 4 | 영상팀 | `ad-video-team` | `04_video.md` | **병렬** |
| 4 | 옥외팀 | `ad-outdoor-team` | `05_outdoor.md` | **병렬** |
| 4 | 혁신팀 | `ad-creative-team` | `06_creative.md` | **병렬** |
| 5 | 대표 검수 | `ad-ceo-review` | `07_review.md` | 순차 |
| 6 | 통합 | (본 skill) | `08_campaign_bible.md` | 순차 |

---

## 1단계: 사용자에게 기본 정보 묻기

캠페인을 시작하기 전 **반드시** 아래를 확인합니다. 사용자가 이미 답했다면 생략하고, 빠진 항목만 질문합니다.

1. **브랜드 또는 제품 이름**이 무엇인가요?
2. **캠페인 목표**가 무엇인가요? (예: 인지도 향상, 구매 유도, 리브랜딩)
3. **타겟**은 누구인가요? (나이, 성별, 관심사 등)
4. **실행 모드**를 선택해 주세요.
   - **자동**: 각 단계 완료 후 사용자 확인 없이 다음 단계 진행
   - **단계별 확인**: 각 단계 산출물 저장 후 사용자 승인을 받고 진행

답변이 모두 모이면 `campaigns/{brand-slug}/` 경로를 확정하고 2단계로 넘어갑니다.

---

## 2단계: AE 호출 (순차)

**에이전트:** `ad-ae` (Task `subagent_type` 또는 해당 에이전트 프로필)

**전달 정보:** 1단계에서 받은 브랜드, 목표, 타겟, 실행 모드

**지시 예시:**
- 브랜드·목표·타겟을 바탕으로 캠페인 방향성 기획서 작성
- 저장 경로: `campaigns/{brand-slug}/01_ae_brief.md`
- 기획서 필수 항목·AE 종합 코멘트는 `ad-ae` 에이전트 정의 준수

**완료 조건:** `01_ae_brief.md` 저장 확인

**단계별 확인 모드:** 사용자에게 기획서 요약을 보여 주고 승인 후 3단계 진행

---

## 3단계: 카피라이터 호출 (순차)

**에이전트:** `ad-copywriter`

**전달 정보:** `01_ae_brief.md` **전체 내용** (파일 경로 + 본문)

**지시 예시:**
- AE 기획서를 읽고 메인 카피·대안 카피 2개·선정 이유 작성
- 저장 경로: `campaigns/{brand-slug}/02_copy.md`

**완료 조건:** `02_copy.md` 저장 확인

**단계별 확인 모드:** 사용자 승인 후 4단계 진행

---

## 4단계: 제작팀 4개 동시 호출 (병렬) — 핵심

**에이전트:** `ad-image-team`, `ad-video-team`, `ad-outdoor-team`, `ad-creative-team`

**전달 정보 (4팀 공통):**
- `01_ae_brief.md` 전체
- `02_copy.md` 전체

**반드시 한 번에 4개 Task를 동시에 호출**합니다. 같은 메시지 안에 4개의 Task 도구 호출을 넣습니다.

| 팀 | 출력 파일 |
|----|-----------|
| 이미지팀 | `03_image.md` |
| 영상팀 | `04_video.md` |
| 옥외팀 | `05_outdoor.md` |
| 혁신팀 | `06_creative.md` |

### 병렬 실행이 되려면 (둘 다 충족)

1. **에이전트 프로필:** 제작 4팀 카드에 `is_background: true` 가 설정되어 있어야 합니다.
2. **오케스트레이션:** 4개 팀 호출을 **같은 단계·같은 턴**에서 묶어 실행합니다. 한 팀씩 순서대로 호출하지 마세요.

둘 중 하나라도 빠지면 순차 실행됩니다. 병렬이 안 되면 에이전트 설정(`is_background`)과 호출 방식(4 Task 동시)을 점검합니다.

**완료 조건:** `03_image.md`, `04_video.md`, `05_outdoor.md`, `06_creative.md` **4개 모두** 저장

**단계별 확인 모드:** 4개 파일 요약을 보여 주고 승인 후 5단계 진행

---

## 5단계: 대표 검수 (순차)

**에이전트:** `ad-ceo-review`

**전달 정보:** `01_ae_brief.md` ~ `06_creative.md` **전체 6개 파일** 경로 및 내용

**지시 예시:**
- 채점 항목별 10점 만점, 총점 산출
- 50점 이상 → 통과, 50점 미만 → 재작업 팀·항목 구체 지시
- 저장 경로: `campaigns/{brand-slug}/07_review.md`

**완료 조건:** `07_review.md` 저장 및 통과/재작업 판정 확인

---

## 6단계: 캠페인 바이블 통합

### 통과(50점 이상)인 경우

`01` ~ `07` 및 제작팀 산출물을 **하나의 실행 문서**로 통합합니다.

**저장 경로:** `campaigns/{brand-slug}/08_campaign_bible.md`

**바이블 구조:**

```markdown
# {브랜드} 캠페인 바이블

## 0. 캠페인 개요
- 브랜드 / 목표 / 타겟 (1단계 요약)

## 1. AE 기획서
(01_ae_brief.md 내용)

## 2. 핵심 카피
(02_copy.md 내용)

## 3. 이미지 광고
(03_image.md 내용)

## 4. 영상 광고
(04_video.md 내용)

## 5. 옥외 광고
(05_outdoor.md 내용)

## 6. 혁신 아이디어
(06_creative.md 내용)

## 7. 대표 검수 결과
(07_review.md 요약: 총점, 통과 여부)

## 8. 실행 체크리스트
- 매체별 론칭 순서
- 담당 팀·산출물 파일 경로
```

이 파일 하나만으로 전체 캠페인을 실행할 수 있어야 합니다.

### 재작업 판정인 경우

1. `07_review.md`에서 **지적된 팀만** 다시 호출합니다.
2. 해당 파일만 수정·덮어쓰기합니다 (`03`~`06` 중 해당 팀).
3. 수정된 산출물과 함께 **5단계 대표 검수를 반복**합니다.
4. 통과할 때까지 5~6단계를 반복한 뒤 `08_campaign_bible.md`를 생성합니다.

---

## 진행 체크리스트

```
캠페인 진행:
- [ ] 1단계: 브랜드·목표·타겟·실행 모드 확인
- [ ] 2단계: 01_ae_brief.md
- [ ] 3단계: 02_copy.md
- [ ] 4단계: 03~06 (4팀 병렬 완료)
- [ ] 5단계: 07_review.md (통과/재작업)
- [ ] 6단계: 08_campaign_bible.md (통과 시)
```

## 오케스트레이션 원칙

- 각 단계 산출물은 **파일로 저장**한 뒤 다음 단계에 **경로와 본문**을 전달합니다.
- 서브에이전트 호출 시 저장 경로·입력 파일·금지 사항을 prompt에 명시합니다.
- **자동 모드:** 체크리스트를 끝까지 진행합니다.
- **단계별 확인 모드:** 각 체크포인트에서 사용자 응답을 기다립니다.
- 대표 검수는 `readonly: true` 이므로 파일 수정 없이 `07_review.md`만 작성하게 합니다.
